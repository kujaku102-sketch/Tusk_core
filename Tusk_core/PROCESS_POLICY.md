# Process Policy

変更の危険度（`P0`〜`P4`）、必須安全工程、テスト下限を決める正本。技術的難度（`LOW` / `MID` / `HIGH` / `MAX`）とは独立する。

## Process Level P0-P4

| Process Level | 影響範囲 | 必須の安全工程 | テスト下限 |
|---|---|---|---|
| `P0` | 文言、読取専用調査、実行経路へ影響しない文書 | 対象とdiff確認 | 構文、リンク、diff確認 |
| `P1` | 単一ファイル・単一機能の局所的で容易に復元可能な変更 | 開始スナップショット退避、変更可能パス固定 | 対象単体テスト（`focused`） |
| `P2` | 複数ファイル、同一コンポーネントの複数経路、永続設定 | 開始スナップショット退避、互換確認 | コンポーネントテスト（`component`） |
| `P3` | 複数コンポーネント、外部アプリ操作、プロセス連携、利用者データ | 開始スナップショット退避、停止・リカバリー確認 | コンポーネント＋統合・限定実機 |
| `P4` | release、installer、配布物、security境界、破壊的操作 | **人間の明示承認**、完全backup/rollback、監視 | 全体テスト（`full`）＋配布検証 |

## 保護対象（Protected Surfaces）

- **P4強制（人間承認必須）**: 認証・秘密情報（`.env` / 鍵）、配布マニフェスト・インストーラ、不可逆な削除・破壊操作。
- **P3強制**: 外部GUI/COMアプリ操作、プロセス停止制御、利用者データ変更、永続スキーマ変更。

## 軽量ルート（Lightweight Route）

`P0` または `P1` かつ `LOW` / `MID` の局所作業では、複数サブエージェント分割や全体回帰を省略し、以下のみで迅速に完結できる：
1. `tusk_manager.py session start` で対象 `scope` の開始スナップショットを記録
2. 限定編集と静的・単体検証（`focused`）
3. `tusk_manager.py session complete` でスコープ外汚染がないことを確認して完了
