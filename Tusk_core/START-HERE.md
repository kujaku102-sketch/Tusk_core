# Tusk Core: start here

1. AIは`AGENTS.md`、人間は`README.md`を読む。
2. 共通実装規則は`GENERAL.md`を読む。
3. 呼出側が選択したExtensionだけを、`EXTENSION_POLICY.md`に従って読む。
4. 対象の現行Specと、Git差分を確認する。
5. エラー処理は`ERROR_POLICY.md`と`ERROR_CODES.md`を読む。
6. Focus Cacheは`EXTENSION_POLICY.md`、Context Cacheは作業領域の文書に従い、必要な場合だけ読む。

不足、重複、曖昧な入力を推測で補完しない。
