# Tusk Core: start here

1. AIは`AGENTS.md`、人間は`README.md`を読む。
2. Sharpenerの状態が`healthy`または明示的waiverであることを確認する。
3. 共通実装規則は`GENERAL.md`を読む。
4. `extensions.json`は配布catalogとして読み、ローカルactivationとmanifest検証を通った拡張だけを有効化する。
5. 対象の現行Spec、Git差分、`TEST_POLICY.md`と`TEST-MAP.json`を確認する。
6. エラー処理は`ERROR_POLICY.md`と`ERROR_CODES.md`を読む。
7. 必要な場合だけ`CONTEXT_CACHE_SPEC.md`または`FOCUS_CACHE_SPEC.md`を読む。
8. Drive書込・引渡し前だけ`SYNC_POLICY.md`を読む。

不足、重複、曖昧な入力を推測で補完しない。
