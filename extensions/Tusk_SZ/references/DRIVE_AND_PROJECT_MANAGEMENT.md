# Siege-Zeke Drive and project management

The common Drive root is folder `1yLQKxHxHjktl7frBAVZ-Vh7Sjm18G-T3`.
Tusk SZ may inventory this folder's direct children. Access below a child needs
a registered project parent or approved work-item child.

Management order is Tusk SZ global, project parent, then work-item child. The
parent owns architecture, progress, canonical direction, synchronization,
required portable data, and child index. The child owns one implementation,
repair, ruling, migration, or sync contract. Read both before product edits.

Drive is transport. Pull into a run stage, compare remote/local/accepted hashes,
then explicitly apply. Push fixed IDs only and verify exact bytes before moving
the checkpoint. Concurrent changes, duplicate names, wrong parents, or unknown
authority stop as `SYNC-409`. Never delete, trash, change sharing, select by
timestamp, or automatically merge.
